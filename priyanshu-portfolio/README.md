# Priyanshu Kanojia — Portfolio

A responsive, single-page personal portfolio built with plain HTML, CSS and JavaScript.

## Run locally
- Open `index.html` directly in a modern browser, or
- From this folder run: `python3 -m http.server 8000`
- Visit `http://localhost:8000`

No npm install, build step, framework, or API key is required.

## Deploy
### GitHub Pages
1. Create a new GitHub repository (or use a portfolio repository).
2. Upload `index.html` (and this README).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.

### Vercel / Netlify
Import the repository or drag the folder into the hosting dashboard. Use the default static-site settings; no build command is needed.

## Personalization
All content is in `index.html`. Update the project links, achievements, skills, and email as needed. The Google Fonts import is optional; the page has sans-serif fallbacks.

## Notes
- This is an original implementation inspired by an immersive, dark, motion-led portfolio aesthetic. It does not reuse the reference repository's code or proprietary assets.
- The portfolio uses the GitHub and LinkedIn details supplied / publicly visible at build time. Review all project and achievement descriptions before publishing.
